# seis-606-homework-1
SEIS 606 Homework 1: Vibe Coding App Ideas

1. Workout & Fitness Progress Tracker

An app that allows users to record workouts, track improvements, and visualize their fitness progress over time.

2. Student Budget & Expense Tracker

An app that allows college students to record expenses, categorize spending, and visualize monthly spending patterns using charts.

3. Internship Application Tracker

An app that helps students track internship applications, application deadlines, interview dates, and application statuses.

4. Personal Finance & Savings Goal App

An app that helps users set savings goals, track income and expenses, and estimate how long it will take to reach their financial targets.

5. Data Cleaning Assistant

An app that allows users to upload a CSV file, identify missing values and duplicates, and generate a basic data quality report.
